Open the Scan tab, allow camera access when the browser asks, and choose the camera you want to use from the dropdown. If the code is far away, you can increase the zoom slider. Then tap Start Scanner. Keep the QR code or barcode inside the scanning frame and the app will detect it automatically. Once it is scanned, the result will appear in the result panel where you can copy the text, save it as a text or CSV file, or export the data in another supported format.

Go to the Scan File tab. Drag a QR code or barcode image into the upload area or click the box to browse your device. After the image is selected, tap Analyze Image. The app will read the code from the uploaded file and show the decoded result instantly, even if you are offline.

Open the Generate tab and choose the type of code you want to create, such as Text, URL, WiFi, Contact, Email, SMS, Location, Event, or Barcode. Fill in the required fields for that type, then expand Customize Appearance if you want to change the code colors, size, or style. After that, click Generate Code. Your code will appear in the preview area, and you can download it as an image or share it directly from the app.

Open the PDF to JPG tool from the Pro Tools tab. Upload a PDF file, choose the page range if needed, and begin the conversion. The tool will convert each page into a high-quality JPG image file, and once the process finishes you can download the generated images to your device.

Select multiple PDF files from your device, arrange them in the requested order, and click Merge. The app combines them into a single document and lets you download the final file as one PDF. This is useful for combining reports, invoices, or scanned pages into one readable file.

Upload a PDF, choose the page range you want to separate, and run the split action. The tool generates a new PDF containing only those selected pages so you can quickly share, archive, or organize large documents.

Open the Word Counter tool and paste or type your text. The app instantly calculates words, characters, sentences, paragraphs, and reading time. This is useful for essays, blog posts, captions, and messages where you need to stay within a limit.
